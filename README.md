# Telecom Network Recon Tool

> Python-based network reconnaissance tool for telecom and cybersecurity environments.

---

## Features

- TCP Port Scanning
- Banner Grabbing
- Multi-threaded Scanning
- Hostname Resolution
- Lightweight & Fast

---

## Technologies

- Python 3
- Socket Programming
- Threading

---

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/telecom-network-recon.git
cd telecom-network-recon
python3 scanner.py
```

---

## Demo

Example target:

```bash
scanme.nmap.org
```

Example output:

Service Banner: SSH
